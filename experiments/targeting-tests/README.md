# targeting-tests/

Скрипти тестових збірок перед 0.1.10: відновлення нижнього трикутника прицілу (U+00AB → гліф U+00AC) і повних UTF-8 імен у редакторі персонажів.

**Статус:** завершено, результат увійшов у 0.1.10 / 1.1.10. Скрипти збережено як історію методу: тестовий пакет збирався поверх попереднього релізу, у UAP змінювалися лише чотири FNT і ID 85, а встановлення робилося з резервною копією й записом доказів.
Вони посилаються на шляхи старого репозиторію (`releases/v0.1.9`, `release/`) і **не запускаються як є**. Сучасний еквівалент: правка в `translations/` або `assets/` → `python -m ua build` → `python -m ua install --game <копія гри>`.

Опис дослідження: `docs/research/fonts.md` (приціл) і `docs/research/character-editor.md`.
