# Логотип титульного екрана

Витягнуто з установленої Steam PC-версії гри 3 жовтня 2026 року.
Це дві текстури з прозорістю, вбудовані в `LEVELS/TITLES/TITLES_US_PC.GSC`.
Фон карти не є частиною цих зображень.

- `indiana-jones-logo.png` — LEGO + Indiana Jones, 1024×256, RGBA.
- `original-adventures-subtitle.png` — The Original Adventures, 512×64, RGBA.

Для перекладу відкрийте PNG у графічному редакторі, замініть потрібний напис
і збережіть під новою назвою з суфіксом `-ua.png`. Збережіть розміри полотна,
прозорість і положення елементів: гра задає розташування цих двох текстур
окремо. Шрифти Adventure та Adventure Subtitles можна використовувати
під час підготовки нового зображення; сама гра показує вже готові пікселі.

У `originals/` збережені початковий GSC-контейнер і дві DDS-текстури
з усіма mip-рівнями. `manifest.json` містить їхні зміщення, розміри та SHA-256.
PNG — декодований верхній mip-рівень DDS, без масштабування чи домальовування.

Для встановлення перекладеної графіки потрібно буде перекодувати PNG у DXT5
з відповідними mip-рівнями та вставити DDS у копію GSC. Саме копію GSC
потім встановлюють у гру; PNG напряму гра не читає.

Повторний експорт:

```powershell
python tools/extract_title_logo.py
```

Можна вказати інший контейнер і папку експорту через `--source` та `--output`.

## Українська графіка

Користувач підготував `indiana-jones-logo-ukrainian.png` та
`original-adventures-subtitle-ukrainian.png`. Збірка:

```powershell
python tools/build_title_logo.py
```

Скрипт створює `release/LEVELS/TITLES/TITLES_US_PC.GSC` і
`TITLES_UK_PC.GSC`, змінюючи лише піксельні дані двох DDS-текстур.
Розміри контейнерів, заголовки DDS та всі інші ресурси збережені.
Стиснені прев’ю й контрольні суми лежать у `built/`.

3 жовтня 2026 року обидва ресурси встановлено в гру; SHA-256 перевірено.
Оригінали збережені поруч із файлами гри з суфіксом
`.before-ukrainian-logo` та в `originals/`. Після встановлення гру
запущено через Steam. Структурні перевірки й декодування всіх 42 mip-рівнів
пройшли. Користувач підтвердив коректне відображення остаточної графіки
в грі; результат збережений у стабільній v0.1.1.
