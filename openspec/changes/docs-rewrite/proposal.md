# Proposal: документація нового репозиторію

## Why

Старий README — хроніка спайку на 80 КБ: гравець не знаходить у ньому кнопку
«Завантажити», а розробник — пояснення підходу. Знання про інструменти, шрифти,
культурні адаптації, роль ШІ та перевірку розкидані по `docs/research`,
`spike-notes` і локальних нотатках. Новий репозиторій має пояснювати проєкт
трьом аудиторіям: гравцеві, цікавому читачеві й розробникові.

## What Changes

- Новий `README.md` українською:
  - hero-скриншот головного меню, кнопка на останній реліз, установлення за три кроки;
  - що перекладено і статус «повний переклад»;
  - сумісність: Steam перевірено, Steam Deck — за результатами перевірки автора, GOG не перевірявся;
  - FAQ про антивіруси, видалення;
  - **список інструментів із посиланнями**;
  - підхід і роль ШІ, автори, ліцензії, дисклеймер;
  - короткий англійський розділ About.
- `docs/setup.md`: рецепт отримання гри, QuickBMS, шрифтів і донорів, збірки й
  встановлення для розробника (на основі `repo-foundation`).
- `docs/tooling.md`: повний список інструментів із посиланнями, версіями й
  призначенням, включно з TT Font Studio.
- `docs/approach.md`: як будувався переклад — контекст рядків, глосарій,
  культурні адаптації, роль ШІ, вичитка й живе QA.
- Переписані дослідження в `docs/research/`: шрифти (з доказом збігу з
  Franklin Gothic Medium), формат FNT, UAP і ASI, PC-меню, текстури, редактор
  персонажів і приціл. Сирі логи й JSON-докази лишаються в старому репозиторії.
- `CHANGELOG.md`: повна історія 0.1.0–0.1.10 і новий верхній запис 1.1.10.
- Шаблони GitHub Issues (помилка в тексті, збій гри) з проханням описати
  ситуацію, рівень і додати сейв; альтернативний контакт — Telegram `dimkasmile`.
- Скриншоти автора в `docs/screenshots/` (оптимізовані).

## Capabilities

### New Capabilities

- `project-documentation`: що й для кого має пояснювати документація
  репозиторію, включно з README, інструментами, підходом і дослідженнями.
- `player-feedback`: як гравці повідомляють про проблеми й що для цього потрібно.

(немає)

## Impact

- Файли: `README.md`, `CHANGELOG.md`, `docs/**`, `.github/ISSUE_TEMPLATE/**`,
  `docs/screenshots/**`.
- Залежить від структури й команд з `repo-foundation`.
- Тексти `docs/` стають джерелом для сторінок сайту в `pages-site`.
