# tools/

Дослідницькі й допоміжні інструменти. Основний шлях збірки — `python -m ua`. Ці скрипти потрібні, коли треба дослідити або змінити щось глибше.
Запуск: з кореня репозиторію, `python tools/<тека>/<скрипт>.py` (корінь потрапляє в `sys.path` автоматично).

| Тека | Що там | Потрібно |
|---|---|---|
| `fonts/` | конвеєр Font 1/Font 2 (його викликає `ua build --level full`), перевірки розкладки й базової лінії, аудит гліфів UI, `inspect_font_crash.py` | `game/`, `local/donors`, `local/fonts` |
| `fonts/glyph_viewer/` | веб-переглядач прямокутників гліфів поверх атласу; `export_glyph_atlas.py` генерує дані в `build/` | зібраний FNT |
| `textures/` | експорт усіх текстур з GSC, OCR-каталог тексту на текстурах, робота з логотипом | `game/` (повне видобування `ua extract --all`), Tesseract для OCR |
| `pc-menu/` | пошук і перевірка таблиці PC-меню в `LEGOIndy.exe` | встановлена гра |
| `runtime/` | керування грою без фокуса й кадри з гри (`live.py`, див. [docs/setup.md](../docs/setup.md#7-жива-перевірка-тестовий-режим)), живі тести в копії гри (`live_test.ps1`), читання пам'яті процесу (`verify_runtime.py --pid`) | `live.py`: встановлення `--test-mode`; решта: копія гри в `local/test-game` |
| `saves/` | перейменування власних персонажів у сейві, тест цього скрипта | файл сейву |

Для ширшої роботи з FNT є браузерний редактор TT Font Studio: https://drsmile444.github.io/tt-font-studio/.

## Перевірка шрифтів x4

`ua/pipeline/font_hd.py` малює Font 1 з гарнітури Franklin Gothic Medium, а Font 2 — з
пікселів гри й гарнітури Adventure, у чотири рази більшими. Ці інструменти в `fonts/`
перевіряють результат. Вхідні шрифти — `build/fonts/font1` і `build/fonts/font2`, їх пише
`python -m ua build --level full`.

- `fonts/check_cells.py` — малює обидва шрифти й шукає гліфи, які втрачають видиме чорнило
  (альфа > 16) на краях клітинки. Font 1: латинська клітинка може зрізати до `OVERHANG` =
  0,75 px на обидва боки разом, кирилична — нічого; верхній і нижній рядки пікселів клітинки
  порожні; код виходу 1, якщо гліф порушує правило. Font 2: втрати українських літер
  виводяться як попередження й не змінюють код виходу. Пише контактні аркуші всіх клітинок
  атласів x4 з рамками: `build/screens/cells-font1.png`, `cells-font2.png`.
- `fonts/letter_gaps.py` — середній і попарний видимий проміжок між сусідніми літерами:
  шрифт гри проти шрифту x4 у масштабі екрана (`--scale`, типово 1,8 для 2560×1440).
  `--font 2` — Font 2 на великих літерах. `--set ключ=значення` тимчасово змінює ключ стилю
  шрифту в `assets/fonts/font_hd.json`, наприклад `--set tighten=0.5` або `--set stretch=1.035`.
- `fonts/show_charset.py` — показує всі символи Font 1 і Font 2 у головному меню гри, по п'ять
  рядків за запуск, і знімає кадри `build/screens/charset-<n>.png`. Потребує встановлення
  `--test-mode` і `UA_STEAM_GAME`; на час роботи підміняє `scripts/UKRAINIAN.uap` гри, потім
  повертає встановлений пакет.

Порядок після зміни шрифту:

1. `python -m ua build --level full` — зібрати шрифти й пакет.
2. `python tools/fonts/check_cells.py` — клітинки цілі, аркуші без обрізаних гліфів.
3. `python tools/fonts/letter_gaps.py` (і `--font 2`) — проміжки між літерами близькі до гри.
4. `python tools/fonts/text_sheet.py` — тексти англійською й українською поряд з оригіналом.
5. `python tools/fonts/show_charset.py` — усі символи в самій грі.
