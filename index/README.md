# index/

Індекс рядків для валідації без файлів гри. Він згенерований з базового релізу командою `python -m ua index`.

- `english_txt.json`: ID → маркер `pc` і токени (`[...]`, `%d`).
- `trc_csv.json`: LABEL → чи перекладається, токени.
- `credits.json`: номер рядка → `heading`/`title`, чи перекладається.
- `pc_menu.json`: кількість рядків PC-меню.
- `fonts.json`: набір символів Font 1 і Font 2. За ним `validate` шукає символи без гліфа.

Тексту гри тут немає, лише структура. Перегенеровувати потрібно тільки тоді, коли змінюється базовий реліз або шрифти.
