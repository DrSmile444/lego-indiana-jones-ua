## A Ukrainian translation, explained in English

This site is mostly read by Ukrainian players, so the translation itself is **Ukrainian only**: installing it turns the game’s English text into Ukrainian. This English version is for international modders, fellow translators and curious players who want to know what was changed in the game and how. The research pages document TT Games’ file formats, fonts and runtime loading in detail.

The first public release is **1.1.10**, and the translation is complete: every in-game string, the save dialogs, the credits and the PC settings menus.

## Three megabytes instead of repacked archives

The translation does not repack hundreds of megabytes of game archives: it is **injected into memory while the game runs**. The package holds only what we changed (the text, two fonts and nine textures), so the whole download is ≈3 MB instead of a ~600 MB set of repacked archives.

- **Nothing is overwritten.** The original `.DAT` archives and `LEGOIndy.exe` stay untouched, so Steam updates never conflict with the translation.
- **Plays well with other mods.** The translation doesn’t claim anyone else’s files and runs through the standard ASI Loader alongside other plugins.
- **Safe in the worst case.** A different game version or a damaged package? The plugin leaves everything alone and the game simply starts in English.

## How we built it

The road from the first unpacked archive to the release: fonts with new glyphs, a custom ASI plugin that serves resources at runtime, textures, a glossary and long live QA sessions. Ideas, decisions and proofreading are the author’s; AI assistants helped with file-format research, tooling and drafts, and every line was reviewed and tested in-game by a human.
