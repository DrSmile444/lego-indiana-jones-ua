# Design: основа нового репозиторію

## Context

Мотивацію описано в `proposal.md`. Джерело міграції — старий репозиторій
`lego-indi-1-ukrainizator-old`, коміт `3b7ff01` (v0.1.10). Його `local/` (≈12 ГБ)
містить видобуту гру, донорські пакети й дослідницькі дампи.

Факти, які визначають підхід:

- `ENGLISH.TXT` — UTF-8 з BOM і CRLF: коментарі `;` і рядки `ID [pc] "текст"`.
  Усі 598 рядків перекладені.
- `TRC.CSV` — UTF-16 таблиця з колонками всіх мов гри. Ми змінюємо лише
  англійську колонку, а решта мов лишається текстом гри.
- Титри (`ENGLISH_CREDITS.TXT`, `PC_ENGLISH_CREDITS.TXT`) містять реальні імена
  й назви студій, які ми навмисно не перекладаємо.
- `UKRAINIAN.uap` (формат UAP1) містить 11 текстових і шрифтових ресурсів,
  рядки PC-меню й дев'ять DDS. ASI підміняє ресурси в пам'яті, а DAT та EXE
  лишаються незмінними.
- База Font 1 — атлас зі сторонньої кириличної латки шрифту (донор). Ми
  перемалювали в ньому вісім гліфів Franklin Gothic Medium і виправили метрики.
  Font 2 зібрано з оригінального `FONT2_PC.FNT` гри й фанатського TTF
  «Adventure».
- Старий білд v0.1.9/v0.1.10 уже працював «ланцюжком»: брав ресурси з UAP
  попереднього релізу й накладав зміни.

## Goals / Non-Goals

**Goals:**

- Чистий клон плюс документований рецепт дають будь-який рівень збірки.
- У git немає файлів гри.
- Побайтове відтворення `UKRAINIAN.uap` v0.1.10 — доказ, що нічого не загублено.
- Один CLI, однакові команди на кожному рівні.

**Non-Goals:**

- Переписування нативного коду: він переноситься як є, з оновленням шляхів.
- Повторне дослідження форматів і адрес пам'яті.
- Документація для людей і сайт (зміни `docs-rewrite` та `pages-site`).
- Публікація релізу (зміна `release-v1-1-10`).

## Decisions

### D1. Три зони вмісту

```
 PUBLIC GIT                    LOCAL (.gitignore)              GITHUB RELEASES
 translations/  (наш текст)    game/   видобуті DAT            lego-indiana-jones-ua-
 index/         (ID+токени)    local/  донори, шрифти,           <ver>.zip
 assets/        (наші гліфи,           базові пакети,          + SHA-256
                 укр. шари)            тексти для публікацій
 native/ ua/ tools/            build/  проміжне
 experiments/ docs/ tests/     dist/   готові пакети
```

Альтернатива — зберігати похідні FNT/DDS у git, як у старому репозиторії. Її
відкинуто: це ресурси гри, і вони роздувають історію.

### D2. Попередній реліз як шаблон збірки

Текстове оновлення бере `UKRAINIAN.uap` базового релізу (URL і SHA-256 у
`manifests/baseline.json`), розпаковує його, накладає JSON перекладу на
TXT/CSV/титри/PC-меню й пакує знову. Шрифти й DDS переходять без змін.

- Альтернатива «скелет без тексту» не підходить: вона не відтворює CSV з
  іншими мовами й титри з іменами.
- Альтернатива «шаблон з `game/`» вимагає гру для кожного виправлення рядка.

**Бутстрап:** доки 1.1.10 не опубліковано, базою є ZIP v0.1.10 у
`local/baseline/` (старий репозиторій приватний). Після публікації маніфест
переходить на ресурс GitHub Release 1.1.10, і будь-хто може збирати без гри.

### D3. Індекс рядків для валідації

`index/*.json` містить для кожного ресурсу ID, маркер `pc`, токени `[...]`/`%d`
і належність до шрифту. Індекс генерується один раз з базового релізу й
перевіряється тестом на відповідність йому. CI не потребує нічого, крім git.

### D4. Шрифти: наш FNT як нова точка відліку

Готові Font 1 і Font 2 — у базовому релізі. Дрібні правки метрик і гліфів
робляться поверх них (TT Font Studio або `ua fonts`).

Повне перезбирання вимагає:
- донорського FNT і TTF «Adventure» у `local/donors/`;
- Franklin Gothic Medium у `local/fonts/`;
- оригінального `FONT2_PC.FNT` з `game/`.

У git ідуть наші вісім гліфів (PNG), параметри рендеру, ручні виправлення
метрик і скрипти. Донорський пакет описано нейтрально як «сторонню кириличну
латку шрифту». Його файли й SHA записані в `manifests/inputs.json`, а
походження розкрито в LICENSE.

### D5. Текстури: наш шар у git, оригінали — ні

У git:
- `assets/textures/<id>-ukrainian.png`;
- проєкти `.af`;
- `manifest.json` із SHA-256 оригінального DDS, SHA-256 його даних після
  128-байтового заголовка (ключ у UAP) і SHA-256 очікуваного результату.

Оригінальні DDS видобуваються з `game/`. Повна інвентаризація 2 700+ текстур і
OCR-каталог стають інструментом (`tools/texture-catalog/`) з документацією, а
не даними в git.

### D5a. Шрифтове дослідження зберігається як документація

Скриншот порівняння TT-атласу з Franklin Gothic Medium і параметри (46.62 pt,
обведення 3 pt назовні, round join) — це наш матеріал. Він іде в
`docs/research/`. Чужий видобутий атлас (`.af`) лежить лише в `local/`.

### D6. Пакет `ua` замість розрізнених скриптів

```
ua/
  __main__.py          python -m ua <command>
  cli.py               doctor | extract | build | install | uninstall | verify | validate | fonts | textures
  formats/             txt.py csv.py credits.py fnt.py uap.py dds.py (з tools/loc, fnt_tool, bc_*)
  pipeline/            text.py fonts.py textures.py native.py package.py
  manifests.py         читання й перевірка manifests/*.json
```

Код форматів переноситься з `tools/loc`, `tools/fnt_tool.py`, `tools/bc_*`,
`runtime/uap/*.py` з мінімальними змінами й тестами. Нативна збірка викликає
`native/build.ps1`. Альтернативу «залишити скрипти як є» відкинуто: через пів
року ніхто не згадає, котрий з ~40 запускати.

### D7. Цільова структура

```
lego-indiana-jones-ua/
  README.md CHANGELOG.md LICENSE LICENSES/
  translations/   english_txt_ua.json trc_csv_ua.json credits_titles_ua.json
                  pc_menu_ua.json glossary.json
  index/          english_txt.json trc_csv.json credits.json pc_menu.json
  assets/
    fonts/        font1/ (гліфи, overrides.json, render.json) font2/ (так само)
    textures/     <id>-ukrainian.png, *.af, manifest.json
    logo/         український логотип і підзаголовок (наш шар)
  native/
    asi/          proxy.cpp, overlay.h, textures.h, custom_names*.h, tests
    vendor/ultimate-asi-loader-9.7.4/  (DLL, LICENSE, provenance.json)
    build.ps1
  ua/             Python CLI (D6)
  manifests/      baseline.json game-files.json inputs.json releases/
  tools/          glyph_viewer/ texture-catalog/ inspect_*/ memory probes
  experiments/    font1-x2/ targeting-tests/ ... (README зі статусом)
  tests/          формати, індекс, відтворення бази
  docs/           (наповнює docs-rewrite)
  .github/workflows/validate.yml
  openspec/
```

`runtime/` перейменовано на `native/`, бо назва описує вміст. `pc-menu`
зливається з `asi`: це той самий модуль у двох режимах збірки.

### D8. Журнал міграції

`docs/migration.md` — таблиця «старий шлях → новий шлях / причина
неперенесення» для кожного відстежуваного файлу старого репозиторію (442) і
для важливих тек `local/`. Це доказ вимоги «нічого не загублено» з
`repository-layout`.

### D9. CI

GitHub Actions на `ubuntu-latest`: `python -m ua validate` + `pytest`. Нативна
збірка й перевірка відтворення бази (потребує базового ZIP) запускаються
локально на Windows; після публікації 1.1.10 відтворення можна перенести в CI
на `windows-latest`.

## Implementation notes (після виконання)

- **Титри без англійських ключів.** `credits_titles_ua.json` (ключ — англійська посада) замінено на
  `credits_ua.json`, де ключ — номер рядка. Індекс позначає 5 посад локалізаційної команди
  в `PC_ENGLISH_CREDITS.TXT`, які навмисно лишилися англійською (`translate: false`).
- **Оригінали текстур** не зберігаються навіть як DDS: `ua/pipeline/textures.py` вирізає їх із GSC у `game/`
  за зсувом і довжиною з `assets/textures/manifest.json` і звіряє SHA-256.
- **Font 1:** полотно (`pcfont_0.dds/png`) вирізається з донорського FNT (`donor[dds_offset:]`), а не зберігається.
- **PC-меню:** `docs/research/pc-menu-text-audit.json` скорочено до `native/asi/pc_menu_table.json`
  (EXE SHA, адреси, 38 оригінальних підписів для перевірки в рантаймі).
- **Версія ASI** береться з кореневого `VERSION` (згенерований `ua_version.h`). `/Brepro` дає однаковий SHA
  при повторних збірках.
- **Тести** на `unittest` зі стандартної бібліотеки (без pytest), CI ставить лише Pillow.
- **Хвостові коментарі** `;was "..."` у перекладених рядках `ENGLISH.TXT` поглинаються регулярним виразом.
  Так було в усіх релізах, і саме на цьому тримається побайтова відтворюваність (задокументовано в
  `ua/formats/txt.py` і тестах).
- **Результати перевірки:** текстова збірка, повна збірка рівня 1 (шрифти + текстури з нуля) і збірка з
  «чистого клону» дають SHA `6f1b…964a`; `native/build.ps1 -SmokeTest -TextureTest` — усі тести зелені
  (21 GSC); `ua install/verify/uninstall` відновлює стан побайтово й блокує чужий loader.

## Risks / Trade-offs

- [Ланцюг релізів: втрата базового ZIP ламає текстову збірку] → Базові пакети
  лежать у GitHub Releases. Рівень 1 (повне перезбирання з `game/`) лишається
  незалежним шляхом.
- [MSVC не дає побайтово однакових DLL] → Критерій побайтовості лише для UAP.
  Для ASI спробувати `/Brepro`, інакше покладатися на тести.
- [Донорський Font 1 недоступний у майбутньому] → Наш FNT уже є точкою
  відліку; донор потрібен лише для архівного перезбирання.
- [Залишкові згадки `local/` і жорстко закодовані шляхи (`D:\Downloads\...`)] →
  Усі шляхи йдуть через `manifests/inputs.json` і конфігурацію `ua`. Тест шукає
  абсолютні шляхи в коді.
- [CSV-шаблон містить інші мови гри] → Він живе лише в базовому релізі й `build/`,
  у git не потрапляє.

## Migration Plan

1. Перенести переклади, глосарій, наші ресурси, нативний код і інструменти
   за D7 без змін поведінки.
2. Зібрати `ua` поверх перенесеного коду форматів, додати індекс і тести.
3. Покласти ZIP v0.1.10 у `local/baseline/`, виконати `ua build`, звірити SHA
   UAP із v0.1.10.
4. Видобути гру через `ua extract`, перезібрати шрифти й текстури, звірити з
   базою.
5. Заповнити `docs/migration.md`.

Відкат: старий репозиторій лишається незмінним. Новий не має комітів, доки
автор не перегляне результат.
