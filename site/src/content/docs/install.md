Українізатор — це ZIP-архів, який розпаковується просто в теку гри. Він нічого не перезаписує: оригінальні файли гри, `LEGOIndy.exe`, DAT-архіви та ваші збереження лишаються незмінними. Переклад підставляється під час запуску.

## Що потрібно

- **LEGO Indiana Jones: The Original Adventures** для ПК (Windows). Перевірено на Steam-версії.
- Мова гри — **англійська** (стандартна для Steam): українізатор замінює саме англійський текст.
- Архів `lego-indiana-jones-ua-1.1.10.zip` зі сторінки [GitHub Releases](https://github.com/DrSmile444/lego-indiana-jones-ua/releases).

| Версія гри | Стан |
|---|---|
| Steam (Windows) | ✅ перевірено |
| Steam Deck | ✅ перевірено |
| GOG | ❔ не перевірено |

## Встановлення

1. **Завантажте** ZIP останньої версії з [GitHub Releases](https://github.com/DrSmile444/lego-indiana-jones-ua/releases) (або кнопкою на [головній](/lego-indiana-jones-ua/)).
2. **Відкрийте теку гри.** У Steam: правий клік на грі → «Керувати» → «Переглянути локальні файли». Зазвичай це
   `C:\Program Files (x86)\Steam\steamapps\common\LEGO Indiana Jones The Original Adventures`.
3. **Розпакуйте архів у цю теку**, поруч із `LEGOIndy.exe`. Після цього там мають бути:

   ```text
   LEGOIndy.exe
   dinput8.dll          ← завантажувач ASI-плагінів
   scripts/
     UKRAINIAN.asi      ← плагін українізатора
     UKRAINIAN.uap      ← пакет ресурсів: тексти, шрифти, текстури
     UKRAINIAN/         ← супровідні файли плагіна
   ```

4. **Запустіть гру** як завжди. Головне меню має бути українською, з новим логотипом.

:::tip[Уже маєте інші ASI-моди?]
Якщо в теці гри вже є `dinput8.dll` від Ultimate ASI Loader, залиште свій файл: нашому плагіну досить того, що тека `scripts/` завантажується. Скопіюйте лише вміст `scripts/`.
:::

## Перевірка архіву (необов’язково)

До кожного релізу на GitHub додано файл `SHA256SUMS` з контрольними сумами. У PowerShell:

```powershell
Get-FileHash .\lego-indiana-jones-ua-1.1.10.zip -Algorithm SHA256
```

Отримане значення має збігатися з рядком для цього файлу в `SHA256SUMS`. У Linux чи на Steam Deck: `sha256sum -c SHA256SUMS`.

## Steam Deck

Перевірено автором на версії 1.1.10. Встановлення таке саме: розпакуйте архів у теку гри (Steam → ⚙ → «Керування» → «Переглянути локальні файли» в режимі робочого столу). Якщо після цього гра лишається англійською, Proton не завантажив `dinput8.dll`. Тоді у властивостях гри → «Параметри запуску» додайте

```text
WINEDLLOVERRIDES="dinput8=n,b" %command%
```

Мова системи в Proton — англійська (США). Починаючи з 1.1.10, переклад покриває й цей варіант, тож окремо нічого налаштовувати не треба.

## Оновлення

Закрийте гру й розпакуйте новий архів у ту саму теку із заміною файлів. Окремо видаляти стару версію не потрібно.

## Видалення

Закрийте гру й видаліть із теки гри:

- `scripts/UKRAINIAN.asi`
- `scripts/UKRAINIAN.uap`
- теку `scripts/UKRAINIAN/`
- `dinput8.dll` — **лише якщо** у вас немає інших ASI-модів, яким він потрібен.

Не видаляйте всю теку `scripts/`, якщо там є файли інших модів. Після цього гра знову запуститься англійською, а збереження працюватимуть як раніше.
