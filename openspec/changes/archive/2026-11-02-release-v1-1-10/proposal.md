# Proposal: перший публічний реліз 1.1.10

## Why

Після переїзду в новий репозиторій локалізацію треба опублікувати як повну
версію: з публічним репозиторієм, GitHub Release, контрольними сумами й
текстами для каналів, звідки приходять гравці. Нумерація 1.1.X відділяє
публічну лінію від дослідницьких 0.1.x, а X продовжує номер останнього
дослідницького релізу (0.1.10 → 1.1.10).

## What Changes

- Схема версій `1.1.X`. Перший реліз — **1.1.10**: вміст 0.1.10 плюс покриття
  мови системи «англійська (США)», знайдене автором на Steam Deck. У пакет додано
  `AMERICAN.TXT`, `AMERICAN_CREDITS.TXT`, колонку AMERICAN у `TRC.CSV` і виправлені
  рядки 1235–1237 та 1449. Шрифти, текстури й PC-меню — як у 0.1.10.
- Збірка пакета 1.1.10 через `ua build --release 1.1.10`, маніфест у
  `manifests/releases/1.1.10.json` (SHA-256 кожного файлу й ZIP).
- Створення публічного репозиторію `DrSmile444/lego-indiana-jones-ua`, перший
  коміт і push — **лише після перегляду й явної згоди автора**.
- GitHub Release `v1.1.10` з ZIP, `SHA256SUMS` і нотатками українською.
  Після публікації `manifests/baseline.json` переходить на цей ресурс.
- Тексти для kuli, Steam (посібник), Telegram і LBK Launcher у
  `local/distribution/`. Вони не комітяться.
- Увімкнення GitHub Pages для сайту з `pages-site`.

## Capabilities

### New Capabilities

- `release-distribution`: як версіонується, пакується, публікується й
  анонсується реліз локалізації.

### Modified Capabilities

- `localization-build`: переклад має діяти в обох англійських локалях; відтворюється UAP поточного релізу, а не обов'язково 0.1.10.

## Impact

- Публічні дії: створення репозиторію, push, Release, Pages. Кожна виконується
  лише за явної згоди автора.
- Залежить від `repo-foundation` (збірка), `docs-rewrite` (README, CHANGELOG) і
  `pages-site` (сайт).
- Старий репозиторій лишається приватним архівом.
