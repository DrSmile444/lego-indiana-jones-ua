# Proposal: сайт проєкту на GitHub Pages

## Why

README добре підходить розробникам, але гравці приходять з kuli, Steam,
Telegram і LBK Launcher. Їм потрібна гарна сторінка з посиланням, де видно
переклад, є кнопка завантаження, інструкція й історія того, як усе зроблено.
Сайт також показує глибину роботи: шрифти, рушій, культурні адаптації, роль ШІ.

## What Changes

- Сайт на Astro Starlight у теці `site/`, публікація на GitHub Pages
  (`drsmile444.github.io/lego-indiana-jones-ua`) через GitHub Actions.
- Власна тема «LEGO × пригоди»:
  - пергамент і сепія, акценти кольорами цеглинки;
  - кастомні SVG: штифти, цеглинка-кнопка, пунктирний маршрут на мапі, компас;
  - без логотипів і фірмових шрифтів правовласників як айдентики.
- Головна:
  - hero зі скриншотом;
  - кнопка «Завантажити» (остання версія з GitHub Releases);
  - три кроки встановлення, галерея скриншотів, слайдер «до/після» головного меню.
- Розділи:
  - встановлення й FAQ;
  - «Як ми це робили» (таймлайн-маршрут);
  - інструменти;
  - дослідження (шрифти, рушій, текстури, PC-меню, редактор);
  - глосарій (генерується з `translations/glossary.json`);
  - культурні адаптації;
  - зворотний зв'язок.
- Сторінки досліджень беруть тексти з `docs/`, щоб не дублювати зміст.
- Повна англійська версія сайту (`/en/`): англійські документи в `docs/en/`, локалізовані компоненти й перемикач мови.

## Capabilities

### New Capabilities

- `project-site`: публічний сайт проєкту — зміст, завантаження, тема, збірка й
  публікація.

### Modified Capabilities

(немає)

## Impact

- Нова тека `site/` (Node.js, Astro Starlight), workflow `.github/workflows/pages.yml`.
- Залежить від `docs-rewrite` (тексти, скриншоти) і `release-v1-1-10` (реальне
  посилання на реліз; до публікації — заглушка на сторінку Releases).
- `site/node_modules`, `site/dist`, `site/.astro` в `.gitignore`.
