# Proposal: основа нового репозиторію

## Why

Старий репозиторій `lego-indi-1-ukrainizator-old` був дослідницьким спайком.
Там 80-кілобайтний README-хроніка, 1,4 ГБ історії, ZIP-знімки, повні GSC-контейнери
й оригінальні ресурси гри в git, а збірки залежать від `local/` і від ланцюжка
попередніх релізів. Тепер, коли все досліджено, потрібен чистий канонічний
репозиторій `lego-indiana-jones-ua`. Він має пояснювати підхід, не містити файлів
гри й дозволяти продовжити роботу з чистого клону без повторних досліджень.

## What Changes

- Нова файлова структура з трьома зонами: публічний git, локальна зона в
  `.gitignore` (`local/`, `game/`, `build/`, `dist/`) і GitHub Releases для
  бінарних пакетів.
- **У git немає жодного файлу гри**: ні оригінальних DDS, ні GSC, ні FNT, ні
  англійського тексту. Для валідації зберігається лише індекс рядків (ID,
  маркери платформи, токени). Шаблоном для збірки слугує наш попередній
  опублікований реліз, закріплений за SHA-256.
- Єдиний CLI `python -m ua` з командами `doctor`, `extract`, `build`, `install`,
  `uninstall`, `verify`, `validate` замість ~40 розрізнених скриптів.
- Рівні відтворення: текстове оновлення без гри (від опублікованого релізу),
  перезбирання шрифтів і текстур (з видобутими файлами гри), нативна збірка
  (MSVC), дослідження наживо (встановлена гра).
- Маніфест очікуваних файлів гри з SHA-256, щоб `extract` і `doctor` одразу
  повідомляли про невідповідну версію гри.
- Перенесення всіх робочих інструментів, нативного коду (ASI, UAP, PC-меню),
  перекладів, глосарію, наших гліфів і українських текстур; експерименти
  переносяться в `experiments/` зі статусом.
- CI-валідація перекладу (JSON, ID, токени, глосарій, покриття гліфів) без
  файлів гри.
- Критерій «нічого не загублено»: з чистого клону збирається `UKRAINIAN.uap`,
  побайтово рівний пакету v0.1.10.

## Capabilities

### New Capabilities

- `repository-layout`: зони вмісту репозиторію, що дозволено в git, а що ні,
  і збереження інструментів та експериментів.
- `game-asset-acquisition`: задокументоване й перевірюване отримання файлів
  гри та сторонніх залежностей з чистого клону.
- `localization-build`: детермінована збірка пакета локалізації з вихідників
  репозиторію на кожному рівні відтворення.
- `translation-validation`: автоматичні перевірки перекладу, які працюють без
  файлів гри.

### Modified Capabilities

(немає: репозиторій новий, специфікацій ще немає)

## Impact

- Новий репозиторій `D:\Projects\lego-indiana-jones-ua`. Старий репозиторій
  лишається архівом досліджень і не змінюється.
- Залежності: Python 3, Visual Studio C++ x86 Build Tools і Windows SDK (тільки
  для нативної збірки), QuickBMS з `ttgames.bms` (тільки для видобування),
  Ultimate ASI Loader 9.7.4 (вендорено з provenance).
- Наступні зміни `docs-rewrite`, `pages-site` і `release-v1-1-10` спираються на
  цю структуру.
