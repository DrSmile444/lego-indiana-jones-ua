# Design: реліз 1.1.10

## Context

Мотивацію описано в `proposal.md`. Пакет 0.1.10 (31.10.2026) має шість файлів:
- `UKRAINIAN.uap` (SHA `6f1b…964a`);
- ASI з рядком журналу `ASI INIT: v0.1.10`;
- loader 9.7.4 (DLL SHA `ec2f…17ab`);
- README.txt;
- дві ліцензії.

Підтримуваний EXE має SHA `c12f…e5fd` (Steam).

## Goals / Non-Goals

**Goals:**
- відтворюваний пакет 1.1.10 з нового репозиторію;
- контрольована публікація;
- готові тексти анонсів.

**Non-Goals:**
- зміни перекладу;
- нові функції;
- збірки для GOG;
- автоматична публікація на сторонніх сайтах.

## Decisions

### D1. Що змінюється відносно 0.1.10

- UAP — шрифти, текстури й PC-меню без змін. Змінені текстові ресурси: `ENGLISH.TXT` (рядки 1235–1237, 1449) і `TRC.CSV` (колонка AMERICAN); додано `AMERICAN.TXT` і `AMERICAN_CREDITS.TXT` (локаль США, Proton на Steam Deck). Шаблони американських файлів беруться один раз із `game/`; після публікації вони вже в базовому пакеті 1.1.10.
- ASI — перезібраний з `native/`, рядок версії `1.1.10`.
- README.txt — номер версії, посилання на сайт і репозиторій, канали
  зворотного зв'язку, інструкція з оновлення з 0.1.x.
- Loader і ліцензії — без змін (LICENSE оновлюється лише за змінами з
  `docs-rewrite`).

Назва ZIP: `lego-indiana-jones-ua-1.1.10.zip`.

### D2. Порядок публікації

```
 [автор переглядає робоче дерево]
        | так
        v
 git commit (один початковий коміт)  -> gh repo create DrSmile444/lego-indiana-jones-ua --public
        |                                         |
        v                                         v
 git push master  -------------------->  CI validate зелений
        |
        v
 gh release create v1.1.10 ZIP SHA256SUMS --notes-file ...
        |
        v
 manifests/baseline.json -> URL ресурсу 1.1.10 (окремий коміт)
        |
        v
 Settings -> Pages (Actions)  ->  сайт живий
        |
        v
 анонси з local/distribution/ (вручну автором)
```

Перед кожною стрілкою, що виходить назовні, потрібне окреме підтвердження
автора.

### D3. Тексти анонсів

`local/distribution/`:
- `kuli.md` — опис для каталогу kuli: назва, автор, версія, розмір, що
  перекладено, встановлення, скриншоти;
- `steam-guide.md` — посібник Steam із BBCode-розміткою, скриншотами,
  встановленням і FAQ;
- `telegram.md` — короткий пост зі скриншотом і посиланням на сайт;
- `lbk-launcher.md` — опис для LBK Launcher (поля уточнюються за вимогами
  платформи);
- `checklist.md` — що де опубліковано, з датами.

### D4. Сумісність у нотатках релізу

Steam (Windows) — перевірено. Steam Deck — за результатами перевірки автора до
публікації: якщо перевірки не було, пишемо «не перевірено». GOG — не
перевірено.

## Risks / Trade-offs

- [Антивіруси позначають `dinput8.dll` / `.asi`] → SHA256SUMS, FAQ, офіційне
  походження loader-а в `provenance.json`; за потреби — посилання на звіт
  VirusTotal у нотатках.
- [Помилка в публічному репозиторії після push] → Немає комітів до перегляду.
  Після публікації виправлення йдуть звичайними комітами.
- [Steam Deck не перевірено до релізу] → Чесний статус, оновлення після
  перевірки.
